# Car.You 🚗💬  
감성 분석 기반 차량 추천 시스템

## 📌 프로젝트 개요
본 프로젝트는 자동차 리뷰 데이터를 기반으로 사용자 감성을 분석하고,  
유사한 리뷰와 차량 스펙 데이터를 통합하여 최적의 차량을 추천하는 시스템입니다.

## 🔍 주요 기능
- 감성 분석 모델 (KoELECTRA, KcELECTRA)을 활용한 리뷰 분류
- SBERT 임베딩 + FAISS 검색을 통한 유사 리뷰 기반 추천
- 감성 점수 + 유사도 통합 추천 알고리즘
- Streamlit 기반 인터랙티브 대시보드 구현
- 워드클라우드 및 차량 비교 시각화 포함

## 🗂️ 주요 파일
| 파일명 | 설명 |
|--------|------|
| `프로토타입_최종.ipynb` | 감성 분석 및 추천 점수 계산 프로토타입 |
| `데이터분석+차량추천_대시보드(최종).ipynb` | Streamlit 기반 추천 대시보드 인터페이스 구현 |

## 💡 기술 스택
- Python (Pandas, NumPy, Matplotlib, WordCloud)
- Transformers (KoELECTRA, SBERT)
- FAISS (유사도 검색)
- Streamlit (웹 대시보드 구현)

## 📁 데이터 설명

본 프로젝트에서 사용된 데이터는 다음과 같습니다.  
저작권 및 용량 이슈로 인해 GitHub에는 업로드하지 않았으며, 데이터 형식과 컬럼 구조는 아래와 같습니다.

| 파일명 | 설명 |
|--------|------|
| `감성+정형_통합_최종_수정.csv` | 차량 리뷰 데이터 + 가격/연료/바디타입 등 정형 데이터 통합본 |
| `car_keywords.csv` | 주요 키워드 및 감성사전 기반 점수가 포함된 CSV 파일 |
| `merged_with_sentiment_and_embedding.pkl` | 감성 점수, 정형 스펙, SBERT 임베딩 벡터가 포함된 통합 데이터 (모델 입력용)

### 📌 주요 컬럼 예시

#### `감성+정형_통합_최종_수정.csv`
- `차명`: 차량명
- `리뷰`: 사용자 리뷰 텍스트
- `avg_score`: 감성사전 기반 점수
- `연료`, `바디타입`, `가격`: 차량 스펙 정보
- `positive_ratio`, `negative_ratio`: KoELECTRA 기반 감성 확률

#### `car_keywords.csv`
- `keyword`: 추출된 주요 키워드
- `weight`: 키워드 중요도
- `sentiment`: 긍/부정 점수

#### `merged_with_sentiment_and_embedding.pkl`
- 감성 점수 + 차량 스펙 + 768차원 SBERT 벡터 포함
- 추천 시스템 모델의 입력으로 사용됨

> ⚠️ 데이터가 필요할 경우 요청 시 별도 제공 가능

## 🖥️ 실행 방법
1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

2. Streamlit 실행:
```bash
streamlit run 데이터분석+차량추천_대시보드(최종).ipynb
```

※ `.ipynb` 실행이 어려운 경우, `.py`로 변환 후 실행 권장

## 🧠 프로젝트 요약
자동차 리뷰에 담긴 소비자의 감정을 정밀하게 분석하고,  
유사한 사용자 리뷰 및 차량 스펙 정보를 결합해 실질적인 맞춤 추천을 제공하는 시스템입니다.  
직관적인 UI와 실사용자 중심 설계를 기반으로 데이터 분석과 서비스 구현을 통합한 사례입니다.
